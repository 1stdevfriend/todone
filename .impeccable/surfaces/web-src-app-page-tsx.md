# Surface: landing page (web/src/app/page.tsx)

Mode: Persuade. Visitor: someone who wants a fast, calm todo app and may live in a terminal. Action: open the web app (primary), install the CLI (secondary), star/self-host on GitHub (tertiary). Proof: the product working in the first viewport (a live mini list mirrored as Markdown), real CLI screenshots from demo/. No invented users, prices or testimonials.

## Direction contract

THESIS: A todo list is a stack of loud, physical stickers you slap down and tick off; the web list and the terminal Markdown are the same thing seen twice. Refuses the calm SaaS screenshot-on-a-soft-gradient hero.

OWN-WORLD: Night ground (near-black) with a Day (cream) switch. Giant condensed uppercase display; workhorse sans for body. Colour as whole blocks: lime, butter, pink, periwinkle, cyan, hot pink. Every object is a sticker: 2-3px black keyline, hard offset shadow, slight tilt; buttons press down into their shadow. Pinned by user references zagged.com + two7square.com.

STORY: See a real list working, tick it, watch the Markdown change, understand "web first, terminal second, same lists, yours"; open the app or copy the install line.

FIRST VIEWPORT: Left 55%: headline in three stacked lines at ~9vw, line two in lime; one-line subhead; primary "Open the app" sticker button + secondary install command chip. Right 45%: a tilted sticker card holding a live 4-task list with subtasks/due/estimate; beneath it, overlapping, a terminal pane showing the same list as Markdown, updating as you tick.

FORM: Pinned fusion (user references), with a raise from the declined brick-instructions challenger: strict numbered step sequence on one module grid. Seed key 35fc1986.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
